# Private Chat Compilation v0 Archive

Status: `experimental-companion`.

This directory preserves the bilingual 2026-09-01 companion compiler prototype. It demonstrated unified rewriting, runtime-aware source semantics, private-chat action selection, and a single final Prompt, but still overlapped with persona definition and testing responsibilities.

It is not a current public entry point. Its useful compilation behavior has been folded into the `compile` mode of the unified Role Prompt Authoring Skill.

Do not append this prototype to a persona card, and do not load it together with the current Skill.
