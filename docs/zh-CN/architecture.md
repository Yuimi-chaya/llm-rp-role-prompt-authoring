## 范围

本仓库定义面向现实一对一私聊的角色 Prompt 作者方法，覆盖角色定义、按运行条件编译 Prompt，以及基于证据的失败诊断。

它不实现宿主运行时、持续世界、工具系统、调度器、记忆数据库、媒体管线或投递服务。

## 唯一公共入口

当前唯一入口是 `skills/role-prompt-authoring/` 下任选一种语言的 Role Prompt Authoring Skill。

`define`、`compile` 和 `audit` 是该入口的内部模式。它们不是三个公共 Skill，也不是需要用户拼接或手工依次调用的三份 Prompt。

```text
普通用户需求
  -> 一个作者入口
     -> 需要时定义角色语义
     -> 条件充分时按运行环境编译
     -> 修改前先审查真实证据
  -> 当前任务需要的一个主要产物
  -> 构建溯源作为不可注入附件单独保留
```

## 三层运行时职责

### 模型层

模型层决定能力上限：

- 指令遵循；
- 多模态语用；
- 长上下文稳定性；
- 推理与歧义处理；
- 采样方差。

Prompt 用于影响行为概率和消除作者侧规则冲突，但不能保证模型无法理解或无法稳定遵循的行为。

模型决定可用的行为分布；实际请求参数由宿主配置并用于从该分布采样。

### Prompt 层

Prompt 层编码已接受的角色语义与互动指引：

- 身份、Canon、人格因果、关系与表达；
- 注意力和解释倾向；
- 私聊互动分寸与可见表达；
- 目标模型必须理解的最小宿主语义；
- 对常见 Prompt 侧失败的软边界。

Prompt 本身不能确立 Canon 真相，也不拥有持久事实、来源权威、实际工具执行或投递状态。

### 宿主层

宿主层负责：

- 来源身份与消息权威性；
- 当前时间、状态、记忆与检索；
- 工具可用性、权限、执行和失败；
- 媒体封装与观察范围；
- 调度、沉默、延迟、主动发送、取消、重试与投递确认；
- 渲染、气泡拆分、引用和传输行为。

当宿主没有可靠提供某项事实或能力时，Prompt 可以保持不确定，但不能制造缺失的保证。

作者工作流位于这三层运行时之外。角色语义源、运行档案、证据和构建记录不是额外运行层，也不会与最终角色 Prompt 一起注入。

## 作者管线

```text
USER_INTENT + CANON
  -> ROLE_SPEC

ROLE_SPEC
  -> PORTABLE_ROLE_PROMPT，运行环境未知时

ROLE_SPEC + compile-ready RUNTIME_PROFILE
  + PRESERVATION_MAP，重写已接受文本时
  -> FINAL_ROLE_PROMPT

EVIDENCE_RECORD
  -> TRIAGE_RESULT
  -> 仅在证据充分时修改拥有该问题的源资产

每次 Prompt 构建
  -> BUILD_RECORD，保留在目标 Prompt 之外
```

最终 Prompt 是构建产物。后续迭代应回到已接受的角色语义和运行事实，而不是无限修补上一版生成文本。

“一个主要产物”指一个面向用户的主要结果和一个可注入角色 Prompt，不表示作者侧只能有一个文件。生产工作流应持久保存带版本的 `ROLE_SPEC` 与最小 `BUILD_RECORD`。只有聊天窗口、没有持久存储时，应把 `ROLE_SPEC` 快照和构建记录作为明确分离、不可注入的附件返回。

## 私聊执行原则

编译阶段可以把以下原则转写成角色特定的自然表述：

- 区分用户原话、平台任务、记忆、工具结果、引用与媒体；
- 区分已确认事实、计划、猜测、临时状态和未知项；
- 让角色视角与自身动机决定现在真正值得回应什么；
- 把输出视为一次真实发送动作，而不是一份完整答复文档；
- 抑制展示性交付偏置：不必通过复述、分析、建议、夸奖、安慰或追问证明理解；
- 保留不完整语义：表情包、符号、残句或多层梗可以只承担语气、节奏或在场感；
- 稳定人格与关系只根据持续证据渐进变化。

这些是作者原则，不是目标模型每轮必须执行的算法，也不是要求输出隐藏思维过程。

## 公开仓库边界

当前公开候选从明确白名单建立，不继承私有研究仓库的 Git 历史。

首发树排除真实部署迭代、真实聊天、内部恢复笔记、benchmark 工作文件和私有配置。后续加入这些材料前，必须单独完成授权、隐私、许可与必要性审查。

## 效果主张

有效主张只能来自同一精确模型、提供商版本、宿主、注入语义、工具、记忆、媒体管线、上下文、采样配置和用户输入下的受控相对变化。

不得声称本方法：

- 让任意模型成为真人；
- 消除 OOC；
- 用一个 Prompt 复现宿主裁决型框架；
- 提供宿主不存在的能力；
- 从一个样本、一个角色或一名评审者的偏好直接泛化。
